# THE WHEEL DEAL - System Architecture

## 1. Project Goal

Build a hyperlocal peer-to-peer vehicle rental platform where vehicle owners can list their vehicles and renters can book them securely.

---

## 2. Problem Statement

People who own vehicles often leave them unused, while others need short-term rentals. Existing rental platforms are expensive or limited. The Wheel Deal aims to connect owners and renters directly.
